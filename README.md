# Не ведись

Лёгкий open-source Android-помощник против телефонного мошенничества. Kotlin + Jetpack Compose. Минимальная версия Android — 10 (API 29).

## Что уже есть в alpha

- Локальный анализ введённой фразы по набору маркеров социальной инженерии: «безопасный счёт», код из СМС, срочный перевод, история про родственника в аварии, установка удалённого доступа, давление и требование тайны.
- Объяснение совпадений, индекс риска и практический совет.
- Вибросигнал при высоком риске.
- Интеграция с Android `CallScreeningService`: после добровольного назначения роли приложение показывает уведомление о входящем номере, который пользователь не добавил в свой локальный список доверенных.
- Список доверенных номеров хранится в локальных настройках приложения.
- Ручная отправка предупреждения через системное меню «Поделиться» в установленный мессенджер. Ничего не отправляется автоматически.
- GitHub Actions: unit-тесты, сборка debug APK и публикация APK как CI artifact.

## Важное ограничение Android

Обычное стороннее приложение не может получить аудиопоток стандартного сотового звонка. Источники `VOICE_CALL`, `VOICE_UPLINK` и `VOICE_DOWNLINK` требуют `CAPTURE_AUDIO_OUTPUT`, которое не предназначено для сторонних приложений. Поэтому эта версия **не слушает собеседника во время обычного звонка**, не записывает разговоры и не заявляет о real-time распознавании речи. Она не показывает ложную плашку «ЭТО МОШЕННИК» только по факту незнакомого номера.

Текущий анализатор проверяет текст, который пользователь сам вставил или ввёл. Входящий номер оценивается отдельно: неизвестный номер — повод быть внимательнее, но не доказательство мошенничества.

## Сборка

Требуются JDK 21, Gradle 8.13 и Android SDK Platform 36.

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Разрешения

- `POST_NOTIFICATIONS` — предупреждения о входящих незнакомых номерах.
- `VIBRATE` — тактильный сигнал при высоком риске в текстовом анализаторе.
- Роль `ROLE_CALL_SCREENING` включается пользователем через системный экран Android.

Нет разрешений на запись аудио, чтение контактов, отправку SMS, доступ к интернету или показ поверх других приложений. Номера доверенных контактов не выгружаются.

## Безопасность и ограничения

- Это эвристический детектор, а не сертифицированный антифрод и не гарантия обнаружения мошенничества.
- Возможны ложные срабатывания и пропуски; мошенники могут менять формулировки.
- Не сообщайте коды, пароли и данные карты; не устанавливайте программы удалённого доступа по просьбе звонящего.
- При сомнении завершите звонок и самостоятельно перезвоните в банк/организацию по номеру с официального сайта или карты.
- Звонки не блокируются автоматически.

## План развития

1. Тестирование CallScreeningService на разных оболочках Android и операторах.
2. Расширяемый словарь мошеннических сценариев с тестами на ложные срабатывания.
3. Отдельное исследование live-распознавания для VoIP/громкой связи — только после проверки доступности аудио на реальных устройствах и с явным согласием пользователя.
4. Необязательное семейное уведомление с минимальными данными и явным включением пользователем.
