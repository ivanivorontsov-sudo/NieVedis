Экспериментальный Android-прототип на Kotlin + Jetpack Compose, целевая версия Android 10+ (API 29). Указанные ниже функции описывают реализацию в исходном коде, а не подтверждённую надёжность или готовность к выпуску.

## Что предусмотрено в коде прототипа (v0.2.0)

### 1. Фильтр входящих звонков (`CallScreeningService`, роль «фильтр звонков»)
Правила (`CallFilterEngine`), всё локально:
- доверенные номера (белый список) и чёрный список, в т.ч. маски `7495123*`;
- режим «только контакты» (нужно `READ_CONTACTS`, контакты не копируются);
- скрытые номера: предупредить / без звука / сбросить;
- номера, которых нет в российской нумерации (+7 0xx/1xx/2xx/5xx) — почти наверняка подмена;
- входящие с 8-800 и платных 8-809/8-803; спутниковые и «глобальные» коды (+870, +881, +882, +883 …);
- звонки из-за границы (можно сбрасывать), номера Казахстана, похожие на российские;
- совпадение с публичными номерами 13 банков, Банка России, Госуслуг и Соцфонда (такие номера часто подделывают);
- провал проверки номера оператором (`VERIFICATION_STATUS_FAILED`, Android 11+);
- настойчивые повторные звонки и серии звонков с соседних номеров (локальная история 7 дней);
- искусственные номера, ночные звонки.
- Три уровня: мягкий (только предупреждения), обычный (очень подозрительные — без звука), строгий (сброс).
- В уведомлении о звонке — кнопки «В чёрный список» и «Доверять».

### 2. Проверка разговора во время звонка (офлайн-распознавание речи)
- Включается в настройках. Когда начинается разговор, приложение предлагает проверить звонок.
  **Разрешение на микрофон спрашивается именно в этот момент**, во время звонка (лучше выбрать «Только в этот раз»).
- Микрофон работает только пока идёт звонок (`READ_PHONE_STATE` → OFFHOOK). Звонок закончился — сервис
  останавливается сразу, плюс сторожевая проверка каждые 2 с. На Android 13+ после звонка приложение просит систему
  отозвать разрешение микрофона (`revokeSelfPermissionsOnKill`; срабатывает, когда процесс приложения завершится).
- Распознавание — Vosk (`vosk-model-small-ru-0.22`, Apache-2.0), модель внутри APK. Звук не записывается и не
  сохраняется; распознанный текст держится в памяти (последние ~80 слов) и стирается после звонка.
- Текст в реальном времени сверяется с базой фраз. При совпадении — громкое уведомление, вибрация и крупная плашка
  поверх экрана звонка: «Похоже на мошенника: …».
- Работает и для звонков в мессенджерах (по режиму аудио `MODE_IN_COMMUNICATION`, Android 12+, при включённой спецвозможности).

### 3. Фильтр СМС и сообщений мессенджеров

> **Правовая оговорка о мессенджерах.** Meta Platforms Inc. признана экстремистской организацией, её деятельность в России запрещена. Пункт 96 перечня Минюста связывает судебное решение с Facebook и Instagram и отдельно указывает, что решения от 21.03.2022 и 20.06.2022 не распространяются на WhatsApp. В этом прототипе WhatsApp не подключается через аккаунт или API: при добровольном доступе Android к уведомлениям проверяется только текст уведомления на устройстве. [Официальный перечень Минюста, пункт 96](https://minjust.gov.ru/ru/documents/7822/).

- СМС (`RECEIVE_SMS`): двойники сайтов банков и Госуслуг, сокращатели ссылок, punycode, ссылки на IP,
  «банк» с обычного мобильного номера, просьбы перезвонить, фразы из базы. **Код, пришедший прямо во время
  разговора, — отдельное громкое предупреждение.** СМС не блокируются и не сохраняются.
- Мессенджеры (доступ к уведомлениям, по желанию): Telegram, WhatsApp, VK, MAX, Viber — проверяется только текст уведомления.

### 4. База подозрительных фраз
- `app/src/main/resources/nevedis/phrases_ru.txt`: **583 шаблона** в **28 сценариях** (служба безопасности банка, безопасный
  счёт, ЦБ, полиция/ФСБ/следователь, Госуслуги, сотовый оператор, родственник в беде, курьер за деньгами, удалённый
  доступ, выигрыши и компенсации, инвестиции, пенсия и Пушкинская карта, счётчики, поликлиника, доставка, военкомат,
  «начальник», взлом мессенджеров, «техподдержка», налоги и приставы, дропы и др.) + 9 защитных шаблонов
  («никому не сообщайте код» в настоящих СМС банков) + 10 базовых правил.
- Сопоставление: стемминг Snowball для русского, ё→е, латинские буквы-двойники («Cбербанк»), опечатка в одну букву,
  до двух вставных слов между словами шаблона, защитный контекст («не переводите на безопасный счёт»), бонусы за
  сочетания признаков («банк» + «код», «родственник» + «деньги», «выплата» + «комиссия»).
- Источники — в [SOURCES.md](SOURCES.md). Фразы сформулированы самостоятельно.

## Ограничения и непроверенный статус
- **Android не даёт обычным приложениям звук собеседника** в сотовом звонке (`VOICE_DOWNLINK` требует системного
  `CAPTURE_AUDIO_OUTPUT`). Микрофон слышит ваш голос, а собеседника — только по громкой связи. Включайте динамик.
- Во время звонка Android отдаёт обычному приложению тишину вместо микрофона, **если не включена его спецвозможность**
  ([документация](https://developer.android.com/media/platform/sharing-audio-input)). Поэтому нужна спецвозможность
  «Не ведись — проверка разговора». Она не читает экран и ничего не нажимает. На Android 13+ для APK не из магазина
  сначала: О приложении → ⋮ → «Разрешить ограниченные настройки».
- Android 14+ запрещает запускать сервис микрофона из фона, поэтому проверка стартует через маленькое окно
  поверх звонка (со спецвозможностью оно открывается само, без неё — по нажатию на уведомление).
- Офлайн-модель Vosk small уступает облачным распознавателям, особенно в шуме и при тихом голосе по громкой связи.
- Фильтр звонков видит только номер. Подделанный номер выглядит как настоящий.
- Блокировать СМС может только приложение СМС по умолчанию, здесь — предупреждения.
- Это эвристика, а не гарантия: возможны ложные срабатывания и пропуски.
- Сборка не проверялась на реальном устройстве и эмуляторе (только unit-тесты).

## Разрешения
| Разрешение | Зачем | Когда спрашивается |
|---|---|---|
| Роль «фильтр звонков» | фильтр входящих | кнопка «Включить защиту звонков» |
| `READ_PHONE_STATE` | узнать, что звонок начался/закончился (номер не читается) | при включении проверки разговора |
| `RECORD_AUDIO` | офлайн-распознавание во время звонка | **во время звонка**, по согласию |
| `FOREGROUND_SERVICE(_MICROPHONE)` | сервис распознавания с уведомлением | — |
| `RECEIVE_SMS` | проверка входящих СМС | при включении фильтра СМС |
| `READ_CONTACTS` | режим «только контакты» | при включении режима |
| `POST_NOTIFICATIONS`, `VIBRATE` | предупреждения | при первом запуске |
| Спецвозможность | микрофон во время звонка, плашка поверх звонка | вручную в настройках |
| Доступ к уведомлениям | фильтр мессенджеров | вручную, по желанию |

**Нет**: интернета (удаляется из манифеста даже если его добавит библиотека), чтения списка вызовов, отправки СМС,
чтения экрана.

## Сборка
JDK 17, Android SDK 36. Модель Vosk скачивается при сборке и проверяется по SHA-256 (в git не хранится);
можно подложить локальный файл через `NEVEDIS_VOSK_ZIP=/path/model.zip`.

```bash
./gradlew testDebugUnitTest assembleRelease
```
Подпись релиза: ключ вне репозитория (`NEVEDIS_KEY_DIR` с `password.txt`). Без ключа собирается неподписанный APK.
